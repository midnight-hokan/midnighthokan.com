## 这是什么

《煤龙拳》是一个致敬《街霸2》玩法的 2D 格斗游戏。整个游戏就是**一个 HTML 文件**：没有引擎、没有框架、没有任何第三方依赖，原生 JavaScript + Canvas 从零写起，连 BGM 和音效都是 WebAudio 实时合成的。

两个原创角色，**煤龙**（红衣）和**钢拳**（蓝衣），在矿区的黄昏下对决。背景里的井架，是给我白天那份工作的一个小彩蛋。

整个项目是用 AI 一轮一轮手搓出来的。第一版是几个方块在打架，我一句"太粗糙了，能不能做到街霸2的水准"，后面就一路推到了现在这个样子。

![对战画面：血条、倒计时、像素角色](/images/coal-dragon-fist/fight.png)

## 有什么

- **16 招**，命中普通技之后可以搓招**取消连招**；
- 完整的必杀体系：波动、升龙、旋风（空中也能用）、气满超必杀；
- 投技和中段指令技；
- **上下段防御**按挨打瞬间的方向输入判定，跟原版一样，走路中、收招中都能防；
- 眩晕、倒地起身、连段计数、打击停顿、KO 慢动作白闪；
- 单人对 CPU，或者按 F2 双人对战；三局两胜，投币、选人、VS 动画一个不少；
- 320×180 低清像素渲染，加 CRT 扫描线和暗角，WebAudio 现场合成的 BGM 和音效。

## 怎么玩

| | 操作 |
|---|---|
| P1 移动 | `W` `A` `S` `D` |
| P1 攻击 | `U` 轻拳　`I` 重拳　`J` 轻脚　`K` 重脚 |
| P2 | 方向键 + 小键盘 `4` `5` `1` `2` |
| 投币 / 确认 | `Enter` |
| 切双人 | `F2` |

| 必杀 | 指令 |
|---|---|
| 波动 | ↓ → + 拳 |
| 升龙 | → ↓ → + 拳 |
| 旋风（空中可用） | ↓ ← + 脚 |
| 超必杀（气满） | ↓ → ↓ → + 拳 |

蹲着按键是下段，空中按键是跳击；近身"前 + 重拳"是投技，远身"前 + 重拳"是中段指令技。

| 角色 | 波动 | 升龙 | 旋风 | 超必杀 | 指令技 |
|---|---|---|---|---|---|
| 煤龙 | 炭火波 | 煤龙升 | 燎原旋 | 真空炭火波 | 矿锤肘（中段） |
| 钢拳 | 钢岩波 | 裂地升 | 碎岩旋 | 真空钢岩波 | 碎岩膝 |

**手机上**会自动出现虚拟摇杆和按键，但触屏手感还有问题，暂时更推荐电脑。
